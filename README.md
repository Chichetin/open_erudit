# open_erudit

Веб-«Эрудит» на двоих: сервер поднимается на локальной машине, игроки заходят из
браузеров — по локальной сети или снаружи через быстрый туннель Cloudflare.

Классические правила: доска 15×15, 104 фишки русского набора, пустышки-джокеры,
обмен фишек, пас. Все образованные ходом слова проверяются по словарю
существительных; незнакомое слово любой игрок может добавить прямо по ходу
партии.

## Запуск

```bash
uv sync               # окружение (Python 3.13)
./run.sh              # только LAN: uvicorn на 0.0.0.0:8000
./run.sh --tunnel     # плюс cloudflared, публичный https-адрес
```

Скрипт печатает базовый адрес. Откройте его, нажмите «Создать партию» и
отправьте сопернику **вторую** ссылку: ссылки персональные, по каждой видна
своя стойка фишек. Токен лежит в hash-части адреса — на сервер он не уходит и
в логи не попадает, а в браузере сохраняется в `localStorage`, так что вкладку
можно закрыть и открыть заново.

Для `--tunnel` нужен cloudflared: `sudo pacman -S cloudflared`.

Партия переживает перезапуск сервера: состояние пишется в `data/games/` после
каждого хода.

## Разработка

```bash
uv run pytest         # тесты движка, сервера и словаря
```

Словарь генерируется один раз и лежит в репозитории. Пересобрать:

```bash
uv run --group tools python scripts/build_dictionary.py
```

Устройство проекта: `erudit/` — движок, ничего не знающий про HTTP; `app/` —
тонкий сервер поверх него; `data/` — набор фишек и словарь.
Архитектурные решения — в [`PLAN.md`](PLAN.md), пошаговый план реализации —
в [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md), правила работы
с репозиторием — в [`CLAUDE.md`](CLAUDE.md).
